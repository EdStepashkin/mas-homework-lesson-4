# Research Agent з Власним ReAct Loop 🤖

Research Agent — це інтелектуальний AI-агент, створений на базі архітектури **ReAct** (Reasoning and Acting). 
Ця версія проєкту демонструє глибоке розуміння внутрішньої роботи агентів: ми **повністю відмовилися від готових абстракцій фреймворків** (таких як `create_react_agent` з LangGraph) на користь власноруч написаного ReAct-циклу. 

Агент здатен приймати запити, самостійно вирішувати, які інструменти використовувати, шукати інформацію в інтернеті, аналізувати її та генерувати структуровані звіти у форматі Markdown.

---

## 🌟 Основні можливості та особливості реалізації

- **Власний ReAct Loop**: Повний контроль над циклом виконання. Ми власноруч відправляємо повідомлення в LLM, парсимо відповідь, обробляємо `tool_calls` та повертаємо результати інструментів назад у модель.
- **Інструменти як JSON Schema**: Всі інструменти описані у форматі JSON Schema для Tool Calling API (замість використання магічного `@tool` декоратора).
- **Ручне керування пам'яттю**: Контекст сесії зберігається та передається між запитами через власноруч керований список повідомлень (`messages`), без використання готового `MemorySaver`.
- **Автономний пошук інформації**: Агент використовує пошукову систему DuckDuckGo (`ddgs`) для знаходження релевантних посилань.
- **Глибокий аналіз сторінок**: Аналізує повні тексти статей за допомогою `trafilatura`, очищуючи їх від реклами та непотрібних елементів.
- **Context Engineering**: Інтелектуальне обрізання занадто довгих текстів, щоб не переповнювати контекстне вікно моделі.
- **Промпт-інжиніринг**: Використовується вдосконалений системний промпт із чіткими інструкціями, обмеженнями та правилами форматування.
- **Генерація структурованих звітів**: Уся зібрана інформація записується агентом у готові `.md` звіти за допомогою інструменту `write_report`.

## 🛠 Технологічний стек

- **LLM**: Google Gemini (`gemini-2.5-flash`), ініціалізована через `ChatGoogleGenerativeAI`.
- **Інструменти (Tools)**:
  - `web_search`: знаходження списку джерел.
  - `read_url`: детальне вичитування інформації за посиланням.
  - `write_report`: обов'язковий запис результатів у вигляді Markdown-звіту в директорію `example_output/`.
  - `get_current_time`: отримання поточного часу для розуміння часового контексту.
  - `read_local_file`: читання вже збережених локальних файлів (звітів).
- **Конфігурація**: Pydantic `BaseSettings` (`config.py`).

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone <your-repo-url>
cd homework-lesson-4
```

### 2. Створення віртуального середовища
Обов'язково використовуйте віртуальне середовище для ізоляції залежностей:
```bash
python -m venv venv
source venv/bin/activate  # Для MacOS/Linux
# або
# venv\Scripts\activate  # Для Windows
```

### 3. Встановлення залежностей
Встановіть всі необхідні бібліотеки:
```bash
pip install -r requirements.txt
```

### 4. Налаштування змінних середовища (.env)
Створіть файл `.env` у кореневій директорії проєкту:
```bash
touch .env
```
Відкрийте файл `.env` та додайте ваш API-ключ для доступу до сервісу Gemini API:
```env
GEMINI_API_KEY="AIzaSyYourApiKeyHere..."
```
*(Ваш `.env` вже додано до `.gitignore`, тож не хвилюйтеся про його випадкове потрапляння в репозиторій).*

### 5. Запуск Агента
Запустіть інтерактивний цикл (REPL) для спілкування з агентом:
```bash
python main.py
```

Коли у консолі з'явиться привітання `Research Agent with Custom ReAct Loop (type 'exit' to quit)` та `You: `, можете починати ставити завдання українською мовою.

## 📁 Структура проєкту

- `main.py` — Точка входу, містить REPL цикл з виводом виконаних кроків (`Tool calls` та результати) у консоль.
- `agent.py` — Реалізація класу `ResearchAgent` із власним циклом `stream()`, ручним керуванням історією повідомлень та викликом інструментів.
- `tools.py` — Імплементація функцій інструментів та їх декларація у форматі JSON Schema (`TOOL_SCHEMAS`).
- `config.py` — Налаштування проєкту (Pydantic Settings) та розширений системний промпт (`SYSTEM_PROMPT`).
- `example_output/` — Директорія для згенерованих агентом Markdown-звітів.
